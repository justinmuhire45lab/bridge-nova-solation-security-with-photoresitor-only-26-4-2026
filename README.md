# bridge-nova-solation-security-with-photoresitor-only-26-4-2026
component used :

resistor, buzzer, photoresistor, jumper wire, arduino uno, breadbpard

how it works

Think of it like a see-saw. When light shines on the LDR, LED1 wins and turns on. The moment something comes close and blocks the light, LED1 turns off and LED2 immediately takes over. The two LEDs can never be on at the same time — one always controls the other through the transistor chain.
